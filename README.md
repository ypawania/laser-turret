# laser-turret

Fun little project to learn control theory. 

Watch a laser track you across a room in real time. Powered by OpenCV and YOLO for object segmentation / detection and a servo and ESP32. Added a gyro powered feedback loop for added laser stablization (might have some applications in aerial combait :)

Inspired by how cool biology is. Humans can already do significantly more than this can, and somehow evolution enabled us to subconsciously do all this REALLY FANCY math.

Learned linear algebra and this weird little thing called quaternions and learnt about cool stuff like Kalman Filters and PID control.
